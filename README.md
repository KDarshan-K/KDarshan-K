## 🚀 Featured Projects

### 🚚 [Unified Global Logistics Hub](https://github.com/KDarshan-K/Unified-logistics)
Full-stack logistics platform with real-time tracking and an AI-powered admin query panel.
- Engineered a MongoDB document model achieving **sub-2ms query latency (1.66ms avg)** for lookups and collection fetches
- Implemented geo-based nearest-driver assignment using MongoDB `$near` (10km radius) with live 3-second status polling
- Built a natural-language admin panel (**Groq / Llama 3.1**) that compiles plain-English questions into executable MongoDB aggregation pipelines
- **Stack:** `FastAPI` · `MongoDB` · `Groq` · `Jinja2` · `Postman`

### 🔎 [FinRAG](https://github.com/KDarshan-K/FinRAG-boxbox)
AI-powered Finance RAG system for querying unstructured financial filings (10-Ks, earnings calls) in plain English.
- Automated document ingestion pipeline that extracts, cleans, and semantically chunks dense PDF financial reports
- Integrated **FAISS** vector storage for high-dimensional embeddings and low-latency similarity search
- Connected vector retrieval to a **Groq LLM** inference layer for grounded, citation-backed responses
- **Stack:** `Python` · `LangChain` · `FAISS` · `Groq` · `PyMuPDF`

### 📈 [ForexTrendML](https://github.com/KDarshan-K/ForexTrendML-Boxbox)
End-to-end ML pipeline forecasting USD/INR exchange rate direction using market and macroeconomic indicators.
- Automated ingestion of real-time FX data and asynchronous macro indicators via **FRED** and **Yahoo Finance** REST APIs
- Designed an ETL alignment layer using forward-filling and scaling to merge daily price action with monthly economic releases
- Architected a modular 4-layer pipeline separating ingestion, feature engineering, training, and inference
- **Stack:** `Python` · `Pandas` · `scikit-learn` · `REST APIs` · `ETL`
